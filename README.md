# Laboratorul 6 — Bootstrap

Pagina Tech store refăcută după Raport 5 Web, cu Bootstrap 5.3.8.

Deschide index.html în browser. Bootstrap este inclus local în assets/;
imaginile produselor folosesc aceleași adrese externe ca originalul și necesită internet.

Nu există style.css propriu. Structura folosește card, card-body, btn,
d-flex, flex-wrap, gap, padding, margin, text-center și object-fit-cover.
Valorile inline păstrează culorile și dimensiunile originale, inclusiv
culorile butoanelor prin variabilele Bootstrap --bs-btn-*.
Aspectul este apropiat de original; spațierea și rotunjirea folosesc scara Bootstrap.

Butoanele Buy sunt demonstrative, la fel ca în original; nu există coș sau plată.
